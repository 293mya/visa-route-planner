# Visa Route Planner

Курсовой проект по программной инженерии: веб‑сайт для планирования международных маршрутов с учётом визовых и транзитных требований.

> Официальная тема: «Разработка веб-сайта для планирования международных маршрутов с учётом визовых и транзитных требований».

## Идея проекта

Пользователь задаёт маршрут международной поездки, а сервис связывает каждую страну назначения и транзита с относящимися к поездке требованиями. Результат должен не просто перечислять справочную информацию, а понятно объяснять, где может потребоваться виза, какие транзитные условия действуют и что ещё нужно уточнить.

Проект не заменяет консультацию официальных органов. Для каждого правила планируется показывать источник и дату актуальности.

## Планируемый сценарий

1. Пользователь указывает гражданство и параметры поездки, которые влияют на правила въезда.
2. Задаёт точку отправления, пункт назначения и страны пересадки.
3. Получает маршрут с визовыми и транзитными требованиями по каждому участку.
4. Видит объяснение результата, источники и предупреждения о неполных или устаревших данных.

## Текущий статус

Сейчас проект находится на стадии исследования и проектирования. Утверждены тема и общий смысл продукта; состав первой версии, источники данных и технологический стек ещё предстоит согласовать.

Ближайшие задачи:

- уточнить требования и границы первой версии;
- описать ключевые пользовательские сценарии;
- выбрать проверяемые источники визовых и транзитных правил;
- подготовить прототип интерфейса;
- согласовать архитектуру и технологический стек;
- реализовать первую сквозную версию и покрыть правила тестами.
